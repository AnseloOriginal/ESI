# ESI renderer

The ESI frontend is a vanilla TypeScript application built with Vite.

## Getting started

```sh
npm install
npm run dev
```

## Project structure

- `src/pages/` contains page composition.
- `src/shared/` contains small reusable UI helpers.
- `src/styles/tokens.css` defines the shared color, radius, and shadow tokens.
- `src/styles/` keeps reset, layout, component, and responsive styles separate.

The current dashboard is a static visual foundation. API integration and interactions can be added as separate features later.
